Apigee X operations, as code you can run.

Two proxy bundles, the Terraform that hosts them, certificate renewal into Secret Manager, a capacity planner, a Splunk log report and an Azure DevOps pipeline. Everything is linted, tested or validated in CI. None of it has run against a live Apigee organization, and this page says so below.

What is inside

Each piece answers one part of running an Apigee X platform.

Proxies

orders-api and oauth-token

JWT verification, spike arrest, an environment KVM, response cache with error responses excluded, XML to JSON, a 404 fault, and Basic plus OAuth 2.0 client credentials on the token endpoint.

proxies/

Terraform

Apigee X on Google Cloud

Organization, instance, environments, environment groups, KVM and entries, target servers, and a Secret Manager secret per environment. One environments map drives all of it.

terraform/

Certificates

Renew into Secret Manager

Checks key match, hostnames, chain order and expiry. Writes a new secret version only when the new bundle is safe, never replaces a certificate with an older one, and does nothing on a repeat run.

src/apigee_ops/certs.py

Capacity

Headroom and time to threshold

Peak TPS per proxy, headroom against your instance capacity, and a straight-line estimate of the days until the planning threshold. The planner below runs the same maths in your browser.

src/apigee_ops/capacity.py

Splunk

Daily and weekly report

Parses the JSON line the ML-Splunk policy writes. A test reads the policy XML, so renaming a logged field fails the build instead of silently emptying the report.

src/apigee_ops/logreport.py

Delivery

Azure DevOps pipeline

Lint, test and validate, package a byte-for-byte reproducible bundle, deploy to test, then prod behind an environment approval. The deploy tool is a dry run unless you pass --apply.

pipelines/azure-pipelines.yml

Verified, and what is not

Plain list of what CI proves and what it cannot.

PieceStatusHow
Proxy bundlesLintedapigeelint, 0 errors and 0 warnings on both bundles. Not deployed to an Apigee organization.
TerraformValidatedterraform validate and fmt -check against the Google provider. Never planned or applied.
Certificate renewalTested13 tests with generated certificates and an in-memory store. The Secret Manager client is not exercised in CI.
Capacity and log reportsTestedSynthetic data. The JavaScript model must equal the Python result.
Bundle packaging and deployTestedReproducible zip, request URLs and order checked with a fake transport.
Azure DevOps pipelineParsed onlyStage order and approvals are asserted. It has not run on an Azure DevOps agent.
Postman, JMeter, Apigee runtime behaviorNot includedNeeds a live organization. Nothing here claims it.

Run it

git clone https://github.com/gerardrecinto/apigee-ops && cd apigee-ops
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]" && pytest -q
python -m apigee_ops.capacity data/sample_analytics.csv --capacity-tps 100
python -m apigee_ops.logreport data/sample_gateway.log
npx apigeelint -s proxies/orders-api/apiproxy -f table.js
